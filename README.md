# Keyboard Tester 🎹

A free, browser-based keyboard testing tool.  
Quickly check if all your keys are working without installing extra software.

## 🚀 Features
- Detects key presses in real time
- Highlights pressed keys visually
- Works directly in your browser (no downloads)
- Simple and lightweight — just HTML, CSS, and JavaScript

## 📂 Project Structure
- `index.html` → Main entry point
- `Keyboard Tester.html` → Alternate tester page
- `one-piece-background.jpg` → Background image asset
